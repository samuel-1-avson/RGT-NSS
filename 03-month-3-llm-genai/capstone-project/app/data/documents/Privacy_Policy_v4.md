# Privacy Policy (Internal Guide) v4.0

**Effective Date:** October 1, 2024
**Confidentiality Level:** Internal Use Only

## 1. Customer Data Handling

Strict adherence to GDPR and CCPA guidelines is mandatory.

- **Verification**: Always verify customer identity via three points (Name + Last 4 SSN + Address/PIN) before accessing account details.
- **Data Minimization**: Only access the data necessary for the current interaction. Do not browse history unrelated to the issue.

## 2. Shared Access

- **Prohibited**: Never share login credentials with other agents.
- **Recording**: All calls are recorded for quality assurance. Agents must disclose this if asked ("This call is being recorded for training purposes").

## 3. Data Breach Protocol

If a data breach is suspected (e.g., unauthorized access, phishing attempt):

1. **Isolate**: Lock the affected workstation immediately.
2. **Report**: Contact Security Ops via the `Red Phone` or `security-ops@telco.com` within 15 minutes.
3. **Document**: Log the incident in the Incident Response Portal.

## 4. Third-Party Requests

- **Process**: Requests from law enforcement or third parties for customer data must be directed to the Legal Department. Agents are **not authorized** to release data to external entities without a subpoena handled by Legal.
